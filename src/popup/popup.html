Start Full Profile export?

This often takes about a minute.

The extension will open temporary same-profile LinkedIn detail tabs and merge complete selected sections.

When it finishes, Chrome will open the printer dialog.

If this Chrome popup closes, the export still continues in the background until it finishes or you cancel from the toolbar again.

You can cancel while it is running. Keep Chrome and the original profile tab open.

Open the Info tab for Chrome print tips.

Remove Chrome print header/footer

  1. Open the Chrome print dialog.
  2. Click “More settings”.
  3. Uncheck “Headers and footers”.
  4. Optionally, enable “Background graphics”.

These instructions affect the current browser; they are not specific to the extension.
